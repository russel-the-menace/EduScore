# 高校名单数据

本目录包含从教育部门发布的旧版 `.xls` 文件转换得到的程序友好数据。

## 文件

- `中国普通高校名单.csv` / `中国普通高校名单.json`：2,952 所普通高校
- `中国成人高校名单.csv` / `中国成人高校名单.json`：244 所成人高校

CSV 使用 UTF-8 with BOM，便于 Excel 和代码直接读取；JSON 使用 UTF-8，并包含来源文件名、来源工作表、字段列表、记录数和记录数组。

转换时完成了以下规范化：

- 省份分组标题转换为每条学校记录的 `省级地区` 字段
- 序号转换为不带小数点的字符串
- 学校标识码转换为精确的 10 位字符串，避免科学计数法和整数精度问题
- 过滤标题、空白行和省份分组行

源文件未被修改。可使用 `scripts/extract_xls.py` 重新生成数据。
