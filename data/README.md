# 高校名单数据

本目录包含教育部高校名单、中国留服认证院校查询结果、QS、US News 和软科院校库的程序友好数据。原始表格保存在 `sources/`。

## 文件

- `中国普通高校名单.csv` / `中国普通高校名单.json`：2,952 所普通高校
- `中国成人高校名单.csv` / `中国成人高校名单.json`：244 所成人高校
- `中国留服认证院校名单.*`：由中国留服认证院校查询服务生成
- `2027_QS世界大学排名.csv` / `2027_QS世界大学排名.json`：1,504 所大学
- `2026-2027_USNews世界大学排名.csv` / `2026-2027_USNews世界大学排名.json`：2,604 所大学
- `软科院校库/`：2,971 所院校的统一 CSV、分类 JSON 和来源元数据

CSV 使用 UTF-8 with BOM，便于 Excel 和代码直接读取；JSON 使用 UTF-8，并包含来源文件名、来源工作表、字段列表、记录数和记录数组。

转换时完成了以下规范化：

- 省份分组标题转换为每条学校记录的 `省级地区` 字段
- 序号转换为不带小数点的字符串
- 学校标识码转换为精确的 10 位字符串，避免科学计数法和整数精度问题
- 过滤标题、空白行和省份分组行

源文件未被修改。可使用 `scripts/` 下的转换和抓取脚本重新生成数据。完整来源链接和使用注意事项见仓库根目录 `README.md`。
