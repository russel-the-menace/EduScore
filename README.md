# 中国及世界大学汇总

本项目汇总中国大陆、海外及港澳台院校的中外文名称、国内院校标签和世界大学排名，为院校检索、名称标准化和数据分析提供可复现的基础数据。

## 最终文件

- `data/master/国内头部大学汇总.csv`：软科院校库前 590 所，保留软科排名并标注 985、211、双一流。
- `data/master/国内非头部大学汇总.csv`：其余 2,381 所国内院校，排名留空、按中文名拼音排序，并标注独立学院、民办高校。
- `data/master/国外头部大学汇总.csv`：2,250 所带 US News 名次的院校，按名次排列并补充 QS 名次和中文名。
- `data/master/国外非头部大学汇总.csv`：其余 7,143 所 QS/中留服/US News 未排名院校，按外文名排序并保留 QS 名次和中文名。
- `data/master/国外大学排名匹配审计.json`：记录来源覆盖、匹配方式和无中文名原因统计。

项目还保留各来源的原始或规范化数据，以及生成最终文件的脚本。完整目录、数据来源、版本和重建方式见 `data/README.md`。

## 生成

```bash
python3 scripts/build_university_summaries.py
```

脚本仅自动合并国家一致且名称高度可信的学校。无法可靠判断的相似名称会保留为独立记录，避免误合并同名或近似名称的不同院校。
