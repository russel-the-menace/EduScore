# 中国及世界大学汇总

本项目汇总中国大陆、海外及港澳台院校的中外文名称、国内院校标签和世界大学排名，为院校检索、名称标准化和数据分析提供可复现的基础数据。

## 核心数据

- `output/国内头部大学汇总.csv`：收录软科院校库前 590 所，按软科顺序排列。字段包括中文名、外文名、软科排名、985、211、双一流。
- `output/国内非头部大学汇总.csv`：收录其余 2,381 所国内院校，按中文名拼音排序。字段包括中文名、外文名、软科排名、独立学院、民办高校。
- `output/国外头部大学汇总.csv`：收录 2,250 所带 US News 名次的院校，按 US News 名次排列。字段包括中文名、外文名、USNEWS、USNEWS 所在地、QS。
- `output/国外非头部大学汇总.csv`：收录其余 6,171 所中国留服院校，按外文名排序。字段包括中文名、外文名、QS。

根目录的 `output/` 只保存上述四张核心 CSV；`data/` 只保存来源数据、过程数据和审计结果。完整目录、数据来源、版本和重建方式见 `data/README.md`。
